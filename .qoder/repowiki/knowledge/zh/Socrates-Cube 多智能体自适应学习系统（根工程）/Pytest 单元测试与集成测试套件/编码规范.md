- 每个被测 Agent 都提供同名 `@pytest.fixture`，内部用 `Agent.__new__(Agent)` 构造裸对象并手动注入 mock 依赖，避免触发真实初始化。
- 异步测试统一加 `@pytest.mark.asyncio`，并对 LLM/retriever/repository 等外部 I/O 使用 `AsyncMock` 或 `MagicMock(return_value=...)` 返回固定 JSON 字符串。
- 集成测试在模块开头设置 `os.environ["DATABASE_URL"]` 与 `os.environ["MOCK_MODE"] = "true"`，以 sqlite 内存库和 mock 模式运行。
- SSE 相关用例通过本地 `_parse_sse_events` 把 `data: {json}` 行解析为字典后断言 `event` 字段序列，而非直接断言原始字符串。
- 参数化场景优先使用 `@pytest.mark.parametrize` 覆盖多输入值（如不同 persona、初始 state、资源类型），配合 fixture 共享被测实例。
