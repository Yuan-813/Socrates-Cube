本模块为纯静态配置目录，按 Agent 职责划分为 `prompts/<agent>/` 子目录（orchestrator/route.txt、profiler/onboarding/extract_profile/update_profile.txt、retriever/search_query/query_expansion.txt、diagnosis/surface_error/root_cause/pattern_match.txt、resource_generator/generate_{code,doc,exercise,mindmap,script,infographic}.txt、simulator/simulate.txt、trust/scope_check/source_citation.txt、path_planner/plan_path.txt、challenger/challenge.txt），每个 `.txt` 即一个 LLM System Prompt 模板，使用 `{variable}` 占位符注入运行时上下文。

- `agent_personas.json` 定义 professor/engineer/peer/interviewer 四种输出风格的人设元数据与 `prompt_prefix`，由上层在构造消息时拼接到对应 Agent 的 prompt 前。
- `api_schema.yaml` 以 OpenAPI 3.1.0 声明 `/health`、`/api/v1/chat`（SSE）、`/api/v1/profile/{user_id}` 三个端点及 `StudentProfile`、`SSEPayload`、`AgentLog` 三大组件 Schema，是前后端契约的唯一来源。
- 依赖方向单向：运行时代码读取这些文件，本模块不反向引用任何 Python 包；`.gitkeep` 保证空目录被版本控制跟踪。
