- Prompt 模板统一采用 Markdown 分节（## 标题）+ `{变量名}` 占位符 + 末尾“返回 JSON”约束的结构化写法，便于上层用 f-string / format 注入上下文。
- 诊断类 Prompt（如 diagnosis/*）固定包含 RFC 标准参考框架、错误类型枚举、Few-shot 示例和置信度校准指南四段式结构。
- 生成类 Prompt（resource_generator/*）均提供至少两个 Few-shot JSON 示例，并强制要求输出字段包含 wireshark_filter、wireshark_key_fields、think_question、related_rfc 等教学增强字段。
- Agent 人设在 agent_personas.json 中以 id/name/style/avatar/description/prompt_prefix 五字段元数据组织，prompt_prefix 直接充当 System Message 前缀。
