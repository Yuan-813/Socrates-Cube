- 入口与编排：`start.sh`/`start.bat` 是跨子模块的统一入口，负责创建 `.venv`、安装 `requirements.txt`、复制 `.env.example` 到 `.env`，然后并行拉起后端 `uvicorn src.loopse.main:app --host 0.0.0.0 --port 8000` 与前端 `npm run dev`（端口 5173），并支持 `--mock-mode` 切换离线演示。
- 运行时契约：后端由 `src.loopse.main:app` 暴露 REST + SSE 接口，OpenAPI 文档位于 `/docs`；前端 `frontend_app` 通过 Axios 访问同域 `http://localhost:8000`，并通过 SSE 消费流式回复。
- 配置资源：`config_prompts` 中的 Prompt 模板与 Agent 人设在运行时被后端加载，作为可热插拔的提示词与 OpenAPI 契约来源。
- 数据与构建：`scripts_tooling` 提供数据库初始化、知识图谱/向量库构建、种子注入等一次性运维命令，与测试套件 `tests` 共用同一 Python 环境。
- 依赖约束：`pyproject.toml` 锁定 Python 3.10.*、pytest 自动发现 `tests/test_*.py` 并启用 `asyncio_mode=auto`；`requirements.txt` 声明 FastAPI/Uvicorn/SSE-Starlette/Pydantic/SQLAlchemy 等核心栈，`requirements-vector.txt` 单独管理可选向量库依赖。
