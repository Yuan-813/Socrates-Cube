本模块为扁平的脚本集合，每个文件对应一个独立 CLI 任务，通过 `sys.path.insert(0, ROOT)` 将项目根目录加入 import 路径后调用 `src.loopse.*` 中的持久化与检索层（`db.connection`、`kb.vector_store`、`kb.text_splitter`、`db.repositories`），自身不暴露任何 API。

- 环境准备：`verify_env.py` 检查 Python 版本、核心/可选依赖、`.env` 中讯飞/星火 LLM 密钥以及本地向量索引状态；`init_db.py` / `init_mysql.py` 通过 `src.loopse.db.connection.init_db()` 建表并写入大量随机学生画像与知识节点。
- 数据摄入管线：`download_knowledge_sources.py` → `ingest_docs.py` / `build_knowledge_base.py` → `ingest_pdf.py` / `reingest_with_mineru.py`，按 `data/raw`、`data/cleaned`、`data/vector_db/local_index.json` 三阶段组织中间产物，最终经 `vector_store.add_documents(collection, chunks, metadatas, ids)` 写入 ChromaDB 集合（course_docs / protocol_specs / misconceptions）。
- 知识图谱扩展：`expand_knowledge_graph.py`、`expand_acu.py`、`expand_misconceptions.py`、`phase2_5_evidence.py` 基于 `data/knowledge_graph.json` 的 nodes/edges/cognitive_nodes 结构生成新节点并回写。
- 资源种子：`seed_resources.py` 使用内置 `R()` 构造器批量写入 doc/exercise/mindmap 三类学习资源；`extract_books_to_ts.py`、`read_original_ideas.py` 负责从外部素材转换入库。
- 验证与度量：`check_acu.py`、`check_misconceptions.py`、`verify_all.py`、`verify_cognitive_loop.py`、`run_diagnosis_accuracy_test.py` 用于回归校验；根级 `generate_metrics.py` 直接读 `edu_agent.db` 计算诊断准确率、路径完成率、误解覆盖率、知识点提升率四项展示指标并输出 `outputs/metrics.json`。

依赖方向单向向外：scripts → src.loopse.*（db / kb / orchestrator），scripts 之间无相互 import，仅共享 `data/` 目录约定。
