- 脚本入口统一在文件顶部执行 `ROOT = Path(__file__).resolve().parents[1]; sys.path.insert(0, str(ROOT))`，再按需导入 `src.loopse.*`，避免被当作包运行时的路径问题。
- 所有面向用户的脚本均使用 `argparse` 声明 `--dry-run`、`--reset`、`--db` 等参数，并在 `if __name__ == "__main__":` 分支中解析参数后调用主函数。
- 对第三方可选依赖（chromadb、langchain、dotenv）采用 try/except ImportError 包裹，缺失时降级到本地 JSON 索引或 Mock LLM，保证基础功能可用。
- 向量文档入库遵循固定模式：先 `split_text(content)` 分块，再并行构造 documents / metadatas / ids 三个列表，最后调用 `vector_store.add_documents(collection, docs, metas, ids)`。
- 数据文件路径一律以 `Path(__file__).parent.parent / 'data' / ...` 形式相对项目根定位，禁止硬编码绝对路径。
- JSON 数据读写统一指定 `encoding='utf-8'`，并在读取失败时返回空列表或打印 `[WARN]` 日志而非抛出异常中断流水线。
