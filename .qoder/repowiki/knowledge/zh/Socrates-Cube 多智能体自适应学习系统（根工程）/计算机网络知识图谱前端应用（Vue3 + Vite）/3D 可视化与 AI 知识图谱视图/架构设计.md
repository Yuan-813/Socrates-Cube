本模块由三个独立 Vue 单文件组件 + 两个轻量工具模块组成，按“视图层 → 工具常量”单向依赖：
- `Device3DView.vue`：使用静态 `import * as THREE` 初始化 WebGL 场景，通过 `THREE.Raycaster` 实现点击拾取设备、鼠标拖拽轨道旋转相机，并以 `userData.deviceId` 将 Mesh 与 `DEVICES` 数据绑定。
- `Hardware3DView.vue`：采用 `await import('three')` 动态导入避免 SSR 问题，Three.js 实例集中存放在非响应式 `reactive({})` 对象中防止 Vue 代理开销；内置粒子系统（`THREE.Points`）模拟报文流动，LED 闪烁与设备悬浮动画在 `requestAnimationFrame` 循环内更新。
- `AIKGView.vue`：基于 `echarts/core` + `GraphChart` + `vue-echarts` 渲染力导向图，通过 `/api/v1/chat/message` 调用后端 LLM 生成 JSON 图谱，失败时回退到 `buildDemoGraph` 演示数据；支持 PNG/JSON 导出。
- `utils/kgMap.ts`：纯函数映射表，提供 `kp_xxx` / `acu_xxx` 节点 ID 到中文名称的解析及类型判断，供上层图谱显示复用。
- `utils/animationConfig.ts`：集中导出 `ANIMATION` 与 `THEME` 常量，作为全局动画时长、缓动曲线与主题色的单一事实来源。
依赖方向：三个 View 均不互相引用，仅 `AIKGView.vue` 间接依赖 `@/stores/userStore` 获取用户上下文；工具模块无运行时副作用，可被任意页面按需引入。
