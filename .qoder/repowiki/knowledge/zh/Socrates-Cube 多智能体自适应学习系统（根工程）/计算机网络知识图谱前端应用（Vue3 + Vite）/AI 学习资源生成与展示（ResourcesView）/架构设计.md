本模块采用「视图层 + Pinia Store + API 客户端 + 类型定义」四层结构：
- `ResourcesView.vue` 是单一聚合页面，通过 `mainTab` 在「AI 学习空间 / 智能题库 / 知识图谱 / 知识库管理」四个子面板间切换；其中题库、信息图、PDF 上传等独立流程直接调用 `/api/v1/*` 原生 fetch，不经过 `resourcesApi`。
- `stores/resourceStore.ts` 基于 Pinia `defineStore('resource')` 维护全局资源列表、按类型派生的 computed 过滤（doc/exercise/code/mindmap/script）、以及 `generateResource` / `generateAll` / `loadRecent` 等状态操作，负责去重插入与进度上报。
- `api/resources.ts` 仅封装两类后端接口：GET `/api/v1/resources/` 与 POST `/api/v1/resources/generate`，统一通过 `apiClient`（axios 实例）发起请求并解包 `.data`。
- `types/resource.ts` 集中声明 `ResourceType` 联合字面量与 `LearningResource` 数据模型，被 store 与 api 共同引用以保证前后端契约一致。
依赖方向单向：View → Store → API Client → 后端；类型定义被两侧共享。卡片渲染通过 `cardComponents` 映射表动态选择 `DocCard` / `ExerciseCard` / `CodeCard` / `MindmapCard` / `ScriptCard` / `InfoCard` 组件。
