三个同级 Vue 单文件组件，分别对应三条用户路径：
- `BookshelfView.vue`：以 Tab 驱动的四合一界面（upload/search/qa/stats），通过 `@/api/client` 调用 `/api/v1/kb/*` 完成文本入库、向量检索、统计查询；Q&A 组合调用 kb search + `/api/v1/resources/generate` 构造 RAG 式回答。
- `BookHouseView.vue`：本地数据驱动的书籍目录页，依赖 `@/data/books` 的 `BOOKS`、`searchBooks`、`getBookById` 做前端过滤与详情渲染，并通过 `vue-router` 跳转到 `/bookhouse/:id/read` 进入阅读器。
- `BookReaderView.vue`：三栏布局（左侧目录/缩略图、中间 Markdown 正文、右侧 AI 聊天面板），通过 `useRoute().params.id` 取书，使用 `@/api/chat` 的 `startChatStream` 建立 SSE 流式对话，并将当前章节前 600 字作为上下文注入 prompt。

依赖方向单向向外：views → `@/api/client` / `@/api/chat` / `@/data/books` / `@/utils/markdown` / `vue-router`，模块内部无跨 view 通信，状态全部保存在各自 `<script setup>` 的 `ref` 中。
