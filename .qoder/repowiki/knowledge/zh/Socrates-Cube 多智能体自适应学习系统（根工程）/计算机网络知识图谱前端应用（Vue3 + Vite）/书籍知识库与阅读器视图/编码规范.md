- 每个视图用 `ref<T>()` 声明响应式状态，并在函数内以 `loading.value = true/false` 包裹异步调用，模板按钮通过 `:disabled="loading"` 同步禁用。
- 对外部 API 的错误处理采用 try/catch 后回退到空结果或友好提示文案，不向上抛出异常。
- UI 结构使用 `v-if`/`v-else-if` 条件块按功能分区（Tab 内容、列表/详情视图、加载中/空态/结果态），避免嵌套过深。
- 样式统一写在组件末尾的 `<style scoped>` 中，类名采用 BEM 风格前缀（如 `.bs-*`、`.bh-*`、`.reader-*`）区分不同页面域。
