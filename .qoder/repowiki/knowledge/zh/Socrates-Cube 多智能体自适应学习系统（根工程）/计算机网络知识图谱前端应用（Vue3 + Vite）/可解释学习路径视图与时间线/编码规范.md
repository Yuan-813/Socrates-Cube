- API 层统一以对象字面量导出命名空间（`pathApi.getUserPath / plan / updateProgress`），每个方法返回 Promise 并在 `.then` 中解包 `r.data`。
- 异步操作遵循 loading/error 双标志模式：进入时置 `loading=true, error=null`，catch 分支仅记录 message，finally 重置 loading。
- 状态变更采用乐观更新策略：先就地修改响应式 state（如 `node.status = 'completed'`），再调用 API，失败不回滚。
- 前端类型使用驼峰（`LearningPathNode`）与后端 snake_case（`PathNode`）分离，由 store 在业务侧做映射，避免跨层混用。
- 可选字段通过 `v-if="node.reason_sources"` 条件渲染，配合 `hasPathReasonSources` 类型守卫区分有无来源。
