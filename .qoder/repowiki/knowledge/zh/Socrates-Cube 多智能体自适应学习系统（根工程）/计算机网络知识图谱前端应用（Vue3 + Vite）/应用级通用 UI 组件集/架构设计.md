本模块为扁平的 Vue SFC 集合，按职责拆分为三类：
- 占位/反馈类：`AppEmpty.vue`（可插图标+动作按钮的空态）、`AppError.vue`（固定 WarningFilled 图标+重试事件）、`AppLoading.vue`（spinner/dots/progress 三种 variant + fullscreen 模式）与 `AppSkeleton.vue`（shimmer 骨架行），均通过 `<script setup lang="ts">` + `withDefaults(defineProps<...>())` 暴露 props，并通过 `defineEmits` 向父组件抛出 action/retry/done 等轻量事件。
- 动效容器类：`SplitScreenTransition.vue` 作为一次性全屏遮罩，内部用 ref 驱动 phase-enter/visible/leave 与 reduced-motion 降级路径，完成后 emit('done') 交由上层控制生命周期。
- 业务聚合类：`ResourceCards.vue` 作为资源列表入口，组合 `@/stores/resourceStore` 与 `@/components/resources/*Card.vue` 子卡片，通过 `cardComponents` 映射表 + `<component :is>` 实现按 resource_type 动态渲染。
依赖方向单向向外：仅依赖 `@/utils/featureDetection` 与 `@/stores/resourceStore`，不反向被业务页面以外的组件引用，属于顶层共享原子组件层。
