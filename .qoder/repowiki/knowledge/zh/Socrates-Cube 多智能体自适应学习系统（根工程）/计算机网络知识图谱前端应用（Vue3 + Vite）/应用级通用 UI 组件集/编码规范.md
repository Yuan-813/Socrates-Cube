- 所有组件统一采用 `<script setup lang="ts">` 语法，props 通过 `interface Props { ... }` 声明并用 `withDefaults(defineProps<Props>(), {...})` 提供默认值。
- 对外交互一律使用 `defineEmits<{ name: [] }>()` 定义强类型事件，并在方法中显式调用 `emit('xxx')`，避免字符串事件名。
- 样式全部写在 `<style scoped>` 块内，命名采用 BEM 风格前缀（如 `.app-empty`、`.loading-content`、`.split-top`），并集中定义 `@keyframes` 动画。
- 对动画敏感的场景优先检测 `prefersReducedMotion()` 做降级处理，确保无障碍体验一致。
