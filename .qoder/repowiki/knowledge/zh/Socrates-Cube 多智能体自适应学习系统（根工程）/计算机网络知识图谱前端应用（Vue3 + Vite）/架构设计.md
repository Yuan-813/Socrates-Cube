顶层 `src/main.ts` 作为唯一入口，初始化 Vue 应用、Pinia 状态管理、Vue Router 路由表以及全局样式；各业务模块（登录引导、对话、学习路径、资源库、诊断测评、仿真实验、书籍知识库、职业测评、3D/图谱可视化、系统页面、通用 UI）以 `views/*` 下的独立单文件组件形式存在，由 `router/index.ts` 集中注册并共享同一套布局。

- 数据层：所有子模块通过 `api/*.ts` 中的 Axios 实例访问后端，`authStore.ts` 维护认证态并在请求头注入 token，`composables/useApi.ts` 封装统一调用入口，`mockInterceptor.ts` 配合 `.env.mock` 在开发期切换 Mock。
- 状态层：`stores/` 下按领域划分 Pinia store（auth/chat/path/resource/simulator/user），被对应 views 与 components 订阅。
- 通信层：`composables/useSSE.ts` 为对话与 Agent 链路提供统一的 Server-Sent Events 订阅能力，被 chat_and_conversation 与 diagnosis_assessment 共同复用。
- 类型层：`types/` 集中定义跨模块共享的 TS 接口，避免在各子模块重复声明。
- 构建部署：`vite.config.ts` 配置路径别名、代理与插件链，`nginx.conf` / `vercel.json` 提供多环境部署产物输出约定。
