本模块由一组独立的 Vue 单文件组件组成，按功能分为三类：
- 登录入口：`LoginView.vue`（默认深色毛玻璃 + Canvas 网络拓扑背景）、`LoginViewScheme2.vue`（知识图谱旋转动画变体），均通过 `authApi` 调用 `/api/v1/auth/*` 完成注册、账号密码登录、手机号 OTP、游客模式及 QQ/微信 OAuth 跳转；登录成功后写入 `authStore.login` + `userStore.setUser`，并通过 `SplitScreenTransition` 过场动画后根据 `isFirstLogin` 决定是否进入 `/welcome`。
- OAuth 回调：`OAuthCallbackView.vue` 作为第三方授权码的接收页，解析路由参数后调 `/api/v1/auth/oauth/{provider}/callback`，成功后同样落库 token 并跳转首页。
- 引导流程：`OnboardingView.vue` 为默认实现，`OnboardingScheme1/2/3.vue` 分别提供粒子背景、代码雨、水墨书卷三种视觉风格；所有方案共享同一数据契约——5 步 `steps` 数组（identity/goal/level/target_job/learning_style），支持 single_choice / multi_choice，最终统一 POST 到 `/api/v1/onboarding/submit/${userId}`，写 `localStorage.onboarded_{userId}` 并刷新 profile 后返回首页。
依赖方向单向向外：仅依赖 `@/stores/authStore`、`@/stores/userStore`、`@/api/auth` 与全局 axios/fetch，不反向引用其他业务视图。
