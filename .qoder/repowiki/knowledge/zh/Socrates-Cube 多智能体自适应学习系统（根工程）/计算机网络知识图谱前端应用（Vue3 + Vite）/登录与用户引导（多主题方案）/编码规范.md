- 表单状态统一以 `reactive({ ... })` 定义对象形式，配合 `ref(false)` 控制 loading/error/otpSent 等开关，错误信息集中写入 `errorMsg` 并在 try/catch/finally 中统一处理。
- 登录入口采用 `type LoginTab = 'account' | 'phone' | 'guest'` 枚举 + `activeTab` ref 驱动模板 v-if 分支，注册/登录共用 `handleLogin` 内部按 tab 分发不同 API 调用。
- OTP 倒计时使用 `setInterval` 维护 60s 倒数，组件卸载时在 `onUnmounted` 中 `clearInterval` 清理，避免内存泄漏。
- Canvas 动画遵循 `initXxxAnimation()` 在 `nextTick`/`onMounted` 中启动、`requestAnimationFrame` 循环绘制、`ResizeObserver` 监听容器尺寸变化、`onUnmounted` 中 `cancelAnimationFrame` 释放的标准生命周期模式。
- 引导步骤数据以 `steps[]` 常量声明，每个 step 包含 `id/type/options`，选择逻辑统一通过 `selectOption(stepId, value, isMulti)` 写入 `answers[stepId]`，并用 `isSelected`/`canNext` 计算选中态与下一步可用性。
- 提交引导时统一走 `axios.post(`/api/v1/onboarding/submit/${userStore.userId}`, { user_id, answers })`，成功后写 `localStorage.setItem('onboarded_'+userId,'true')` 再 `userStore.fetchProfile()` 并 `router.push('/')`。
