本模块按职责划分为四层：
- `views/*.vue`：路由级页面组件（WelcomeView 作为首次引导翻书页，HomeView/ProfileView/LogsView/VideoGenView 为业务页面），仅持有展示逻辑与轻量交互，通过 `useUserStore` 读写本地持久化标记（如 `manualRead`）。
- `stores/authStore.ts`、`stores/userStore.ts`：Pinia store，使用 `{ persist: true }` 将 token、用户信息、阅读标记持久化到 localStorage；authStore 在登录时把 Bearer token 注入到全局 axios 请求头，并在 logout 时清理。
- `api/client.ts`：Axios 实例工厂，集中配置 baseURL（优先 `VITE_API_BASE_URL`）、超时与响应错误静默策略（忽略 `/health`）；`mockInterceptor.ts` 通过 `installMockInterceptor` 在 `VITE_MOCK_MODE=true` 时拦截请求返回模拟数据。
- `api/auth.ts`：按领域聚合的 API 函数集，负责把后端 snake_case 响应映射为前端 camelCase 的 `AuthUser`，对外暴露 `login/register/guestLogin/sendOtp/verifyOtp/updateProfile` 等方法。
- `composables/useApi.ts`：通用异步数据 hook，统一封装 loading/error/data 三态与 `immediate` 执行模式，供各页面复用。
- `types/`：共享 TS 类型（agent/chat/sse/index），由 `index.ts` 做 barrel 再导出，被 views/stores/api 共同消费。
依赖方向严格自上而下：views → stores/composables → api → client/mockInterceptor，类型层无运行时依赖。
