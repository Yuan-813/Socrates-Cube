- API 层统一以对象形式导出（如 `authApi`），每个方法先调用 `apiClient.post/get` 拿到原始响应，再用内部 `mapResponse` 把后端 snake_case 字段映射为前端 camelCase 后再返回。
- 认证令牌通过 `authStore.setToken` 写入后同步设置 `apiClient.defaults.headers.common['Authorization'] = 'Bearer ...'`，登出时删除该 header 并清除 localStorage 中的 `user` 与 `auth` 键。
- 页面侧的数据获取普遍采用 `useApi<T>(fetcher, { immediate })` 组合式函数，避免在每个组件内重复编写 loading/error 分支。
- 全局类型集中在 `src/types/` 下按文件域拆分（agent.ts/chat.ts/sse.ts），并通过 `types/index.ts` 做 barrel 再导出，其他模块只从 `@/types` 引入。
