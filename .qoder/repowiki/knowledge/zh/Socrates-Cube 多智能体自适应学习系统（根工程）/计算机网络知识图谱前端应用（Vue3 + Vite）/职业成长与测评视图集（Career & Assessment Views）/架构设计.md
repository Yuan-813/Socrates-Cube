本模块为 Vue 3 `<script setup lang="ts">` 单文件组件集合，按职责分为两类：
- 页面级视图（views/）：CareerView.vue 聚合「技能差距分析 + 简历生成 + 模拟面试」三大子 Tab；ExamView.vue 实现证书考试从选题→答题→成绩报告的三阶段状态机；InterviewView.vue 以 select/running/result 三态驱动 AI 动态出题与逐题评估。
- 通用组件（components/）：RoleSelector.vue 作为首次登录的角色引导弹窗，通过 `emit('done', {roleType, meta})` 向父级回传用户画像；ScopeNotice.vue 是 Element Plus 风格的范围提示条；RegisterSuccessNotify.vue 是顶部滑入的注册成功通知。

依赖方向：视图 → Pinia store（userStore/authStore）→ axios/fetch 调用后端 REST API（/api/v1/career/*、/api/v1/exam/*、/api/v1/question/generate、/api/v1/resources/generate），无跨视图共享逻辑，各视图内部自管响应式状态与计时器（setInterval/onUnmounted 清理）。
