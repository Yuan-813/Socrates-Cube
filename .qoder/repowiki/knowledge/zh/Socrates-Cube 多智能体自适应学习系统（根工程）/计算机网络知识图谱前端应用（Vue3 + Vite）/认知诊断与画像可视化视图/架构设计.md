本模块以 `DiagnosisView.vue` 为路由级页面，仅负责渲染三层诊断引擎概览条并内嵌 `DiagnosisPanel`；`DiagnosisFlowStepper.vue` 通过读取 `useChatStore()` 中的 `lastScopeNotice` / `isStreaming` / `lastDiagnosis` 等状态，将诊断流程映射为 input → diagnosis → graph → repair → update 五个步骤，并支持 scope_blocked 拦截态。

画像展示由两个独立组件承担：`ProfileSummaryPanel.vue` 是轻量版（SVG 环形进度 + 8 维横向进度条 + 最弱3项快捷强化），`ProfileRadar.vue` 是完整版，基于 `echarts/core` 注册 RadarChart/LineChart/GaugeChart 并通过 `vue-echarts` 的 `<v-chart>` 渲染仪表盘、彩色轴标签雷达图、线性渐变成长轨迹折线图，以及可展开的 4×2 维度卡片网格。

数据契约集中在类型层：`types/diagnosis.ts` 定义 `DiagnosisResult` 与 `InterventionRecommendation`，`types/profile.ts` 定义 `StudentProfile` 接口及 `PROFILE_DIMENSION_LABELS` / `PROFILE_DIMENSION_ICONS` / `PROFILE_DIMENSION_DESCRIPTIONS` 三个只读常量表，被 Profile 组件统一引用以保证维度键名一致。依赖方向：视图 → 组件 → Pinia store (`chatStore`/`userStore`) 与 ECharts，类型文件无运行时依赖。
