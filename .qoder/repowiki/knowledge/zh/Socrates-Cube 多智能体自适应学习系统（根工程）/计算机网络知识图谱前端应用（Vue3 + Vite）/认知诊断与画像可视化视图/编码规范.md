- 维度键名采用 snake_case 常量数组（`conceptual_understanding`、`protocol_analysis` 等）在 `profile.ts` 中统一定义，组件侧通过 `Record<string, string>` 映射到中文 label/icon/description，避免硬编码散落。
- 分数等级判定复用同一套阈值函数（≥80 优秀、≥60 良好、≥40 中等、≥20 较弱、其余薄弱），在 SummaryPanel 与 Radar 中各自实现同名 `scoreColor`/`getColor` 与 `scoreLabel`/`getLabel`。
- ECharts 配置全部放在 `computed` 中返回纯对象，直接绑定到 `<v-chart :option="..." autoresize />`，不通过 ref 手动调用 setOption。
- 交互跳转统一通过 `vue-router` 的 `router.push({ path: '/resources', query: { topic } })` 触发资源生成，而非直接修改 URL。
- 组件内部状态（如 `expandedDim`）使用 `ref<string | null>(null)` 管理，切换逻辑为 `value === key ? null : key` 的单选折叠模式。
