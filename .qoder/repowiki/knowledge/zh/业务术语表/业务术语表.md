### 软件杯 A3 赛道
- 定义：第十五届中国软件杯大赛的 A3 赛题，主题为"基于大模型的个性化资源生成与学习多智能体系统开发"。这是本项目参赛的核心赛事背景，评分标准包括创新价值与实用性（占总分35%）以及多个加分项。
- 别名：软件杯A3、A3赛题、中国软件杯

### ACU（Atomic Cognitive Unit）
- 定义：原子认知单元，是本项目知识图谱中的认知层节点，代表学生可以独立掌握的最小认知概念。每个 ACU 包含定义、错误模型、修复策略、验证问题和前置依赖五个维度的完整规格卡。系统通过 50 条常见误解聚类得到 48 个 ACU，形成双层知识图谱结构。
- 别名：原子认知单元、认知单元、acu_xxx

### 三层认知诊断
- 定义：本系统的核心诊断机制，分为三个递进层次：第一层表面错误识别（7种错误类型）、第二层根因溯源（定位缺失的前置知识节点）、第三层误解模式归类（匹配24种常见误解模式）。诊断结果驱动后续的资源生成和学习路径规划。
- 别名：三层诊断、认知诊断引擎、DiagnosisAgent

### 八维画像
- 定义：系统为每位学习者维护的实时认知画像，包含八个维度：知识储备、认知风格、学习进度、协议理解、动手能力、常见错误、学习偏好、综合水平。每轮对话后通过 Profiler Agent 增量更新，前端通过雷达图可视化展示。
- 别名：学生画像、能力画像、ProfileRadar

### 认知干预闭环
- 定义：系统通过"诊断→干预→验证→更新"的完整流程实现认知修复。当 Diagnosis 发现学生的认知误区后，InterventionSelector 选择合适的干预方式（如协议仿真、练习题等），Challenger 进行验证追问，Profiler 更新掌握度，PathPlanner 重新规划学习路径。
- 别名：认知修复闭环、干预闭环、Cognitive Intervention Loop

### 证据模型（Evidence Model）
- 定义：定义如何从学生行为（答题、仿真交互、练习表现）推断 ACU 掌握度的规则集合。目前系统缺失这一关键组件，导致无法回答"凭什么判断学生不会某个 ACU"的问题，是 P2-A'' 阶段需要完成的核心设计。
- 别名：Evidence Model、掌握度计算模型、证据链

### MC（Misconception）
- 定义：常见误解记录，系统内置的 105 条典型学生错误认知模式。每条 MC 包含错误描述、触发条件、严重程度、关联知识点等信息，用于三层诊断中的误解模式匹配环节。
- 别名：误解库、misconceptions.json、误解模式

### SSE 流式输出
- 定义：Server-Sent Events 技术，用于实现多 Agent 协同过程中的实时思考过程展示。后端通过 EventSourceResponse 推送 token 流，前端实时渲染，支持 8 个 Agent 的颜色区分和耗时统计。
- 别名：SSE流式、实时流式输出、Streaming Response

### 虚拟教师
- 定义：基于讯飞超拟人数字人技术的 AI 教学助手，支持实时口型同步和语音朗读。通过 VMS Web SDK 或 WebSocket 直连方案实现，可在 ChatView 中以弹窗形式展示，增强人机交互的真实感。
- 别名：数字人、VirtualTeacher、超拟人数字人

### Z-Library 集成
- 定义：项目内置的外部电子书资源链接功能，通过点击书籍卡片上的"获取原版"按钮跳转到 Z-Library 对应书籍的搜索页面。采用外链跳转方式避免版权风险，仅做资源导航而不存储任何电子书文件。
- 别名：Zlibrary、外部电子书链接、原版电子书
