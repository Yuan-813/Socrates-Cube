## 简介
本技术文档面向“知识图谱系统”，聚焦以下目标：
- 结构化知识表示与实体关系建模
- 语义搜索与向量相似度检索机制
- 知识抽取算法、图谱更新策略
- 向量存储设计、索引优化与查询性能调优
- 误解概念注册表管理与认知偏差检测
- 可视化使用方法与问题排查
- 扩展新领域与导入外部知识库的指引

## 架构总览
系统采用“图谱 + 向量”的双通道检索与增强路径：结构化查询保障精确性，向量检索提升召回率；两者在 API 层融合输出。

```mermaid
sequenceDiagram
participant Client as "客户端"
participant API as "API 层<br/>search.py / knowledge_base.py"
participant KG as "知识图谱<br/>knowledge_graph.py"
participant VS as "向量存储<br/>vector_store.py"
participant DB as "持久化存储"
Client->>API : "提交自然语言查询"
API->>VS : "生成查询向量并检索相似片段"
API->>KG : "执行结构化过滤/关联查询"
KG-->>API : "返回候选实体/关系子图"
VS-->>API : "返回相似片段及分数"
API->>API : "重排序与去重融合"
API-->>Client : "返回结果含引用与解释"
```

### 向量存储与相似度检索
- 文本切分：按语义边界与长度阈值分段，保留上下文窗口。
- 向量化：使用嵌入模型将片段转为高维向量。
- 索引与检索：构建近似最近邻索引，支持 Top-K 检索与过滤条件。
- 混合检索：与结构化查询结果融合，进行重排与去重。

```mermaid
flowchart TD
Start(["开始"]) --> Split["文本切分"]
Split --> Embed["向量化"]
Embed --> Index["构建/更新索引"]
Index --> Query["接收查询向量"]
Query --> ANN["近似最近邻检索"]
ANN --> Filter["应用过滤条件"]
Filter --> Rank["融合与重排序"]
Rank --> End(["返回结果"])
```

### 误解概念注册表与认知偏差检测
- 注册流程：录入概念、典型误解、证据来源与置信度。
- 冲突检测：比较新旧条目语义相似度与证据一致性，提示冲突。
- 消解策略：以权威来源优先、时间戳较新优先、证据强度加权。
- 偏差检测：在问答或诊断链路中，结合注册表进行风险预警与干预建议。

- 索引优化：合理设置 Top-K、过滤维度与缓存策略，降低重复计算。

## 故障排查指南
- 构建失败：检查数据源完整性、解析器日志与切分参数。
