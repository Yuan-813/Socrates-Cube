## 设计原则
1. 总时长控制在 60-90 秒
2. 分为 4-6 个场景，每场景有明确的教学目标
3. 每场景包含：场景描述、旁白文案、视觉备注
4. 语言通俗易懂但不失专业性，适合大学生
5. 第一个场景引入问题/困惑（激发认知冲突）
6. 中间场景展示协议工作原理（使用动画/时序图）
7. 最后一个场景总结要点并引用RFC标准
8. 涉及协议交互时使用时序图风格的视觉设计

## 网络协议可视化指南

### 推荐的视觉元素
- **数据包动画**：彩色方块在节点间移动，标注关键字段值
- **协议状态机**：节点高亮+箭头表示状态转换
- **分层封装**：俄罗斯套娃式展示PDU嵌套过程
- **时序图**：垂直时间线+水平箭头表示消息交互
- **拓扑图**：网络设备图标+连线表示网络结构
- **数据流可视化**：管道模型展示带宽/流量概念

### 协议教学的最佳视觉化策略
| 知识类型 | 推荐视觉化方式 |
|---------|--------------|
| 协议交互流程 | 时序图动画（SYN/ACK箭头飞行） |
| 报文格式 | 逐字段高亮的包头结构图 |
| 分层封装 | 数据下行时逐层添加"信封"效果 |
| 状态转换 | FSM状态气泡图+高亮当前状态 |
| 路由过程 | 拓扑图中数据包逐跳移动 |
| 拥塞控制 | 动态折线图展示cwnd变化曲线 |
