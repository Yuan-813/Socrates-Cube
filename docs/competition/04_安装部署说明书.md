## 一、系统运行环境要求

### 1.1 服务端环境

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Windows 10 / Ubuntu 20.04 / macOS 12 | Windows 11 / Ubuntu 22.04 |
| CPU | 双核 2GHz | 四核 3GHz |
| 内存 | 4 GB | 8 GB |
| 磁盘空间 | 2 GB（含依赖和数据） | 5 GB |
| Python 版本 | **3.10.x（严格约束）** | Python 3.10.14 |
| Node.js 版本 | 18.x | 20.x LTS |
| 网络 | 可选（LLM API 访问）| — |

> **Python 版本约束说明**：系统使用 `aiosqlite 0.20.0` 等组件对 Python 3.10 有兼容性依赖，**严禁使用 3.11+ 或 3.9-**，否则部分异步 SQLAlchemy 功能将出现兼容性问题。

### 1.2 客户端环境

| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome 100+ / Firefox 100+ / Edge 100+ / Safari 15+ |
| 特性依赖 | HTML5 WebSocket、Server-Sent Events、Canvas 2D API |
| 屏幕分辨率 | ≥ 1280×720（推荐 1920×1080） |

### 1.3 外部服务（可选）

| 服务 | 用途 | 不可用时降级 |
|------|------|-------------|
| 讯飞星火 Spark-X API | 主 LLM | 自动启用 Mock 模式 |
| ARK/Doubao API | 备用 LLM | 仍使用讯飞；均不可用时 Mock |
| ChromaDB | 向量检索 | 降级至本地索引 |

## 二、安装步骤

### 方式一：Windows 一键启动（推荐用于演示）

系统提供 `start.bat` 一键脚本，自动完成环境初始化：

```bat
# 进入项目根目录
cd d:\git-projects\Socrates-Cube

# 双击运行，或在 PowerShell/CMD 中执行：
.\start.bat
```

`start.bat` 自动执行以下步骤：
1. 检测 Python 3.10 是否可用；
2. 创建虚拟环境 `.venv`（如不存在）；
3. 安装后端依赖（`pip install -r requirements.txt`）；
4. 初始化数据库（`python scripts/init_db.py`，含演示账号）；
5. 启动后端服务（`uvicorn src.loopse.main:app --host 0.0.0.0 --port 8000`）。

**前端需单独启动**（首次运行）：

```powershell
cd frontend
npm install
npm run dev
# 访问 http://localhost:5173
```

---

### 方式二：手动安装（适用于所有平台）

**Step 1：克隆/解压项目**

```bash
# 解压提交的源码包，或克隆仓库
cd /path/to/Socrates-Cube
```

**Step 2：创建 Python 虚拟环境**

```bash
# Windows PowerShell
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Linux / macOS
python3.10 -m venv .venv
source .venv/bin/activate
```

**Step 3：安装后端依赖**

```bash
pip install -r requirements.txt
```

**Step 4：配置环境变量**

将 `.env.example` 复制为 `.env` 并填写配置：

```bash
cp .env.example .env
# 编辑 .env 文件
```

**Step 5：初始化数据库**

```bash
python scripts/init_db.py
# 创建11张数据表 + 3个演示账号（demo-student-001/002/003）
```

**Step 6（可选）：构建知识库**

```bash
# 导入课程文档到 ChromaDB（首次使用或知识库为空时）
python scripts/ingest_docs.py

# 验证环境配置
python scripts/verify_env.py
```

**Step 7：启动后端服务**

```bash
uvicorn src.loopse.main:app --reload --host 0.0.0.0 --port 8000
```

**Step 8：安装并启动前端**

```bash
cd frontend
npm install
npm run dev    # 开发模式，访问 http://localhost:5173
# 或
npm run build  # 生产构建，输出到 dist/ 目录
```

---

### 方式三：Docker Compose 部署

系统提供 `docker-compose.yml` 配置文件，支持容器化一键部署：

```bash
# 构建并启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看后端日志
docker-compose logs -f backend

# 停止服务
docker-compose down
```

**Docker Compose 服务配置：**

| 服务名 | 端口映射 | 说明 |
|--------|---------|------|
| backend | 8000:8000 | FastAPI + Uvicorn |
| frontend | 80:80 | Vue3 + Nginx 静态服务 |

> **注意**：Docker 方式需提前将 `.env` 文件中的 LLM API 凭证配置正确，或不配置以启用 Mock 模式。

## 三、环境变量配置

### 3.1 必填变量（LLM 功能）

不配置以下变量时，系统自动进入 **Mock 模式**（所有 LLM 调用返回预置响应，演示功能完整）：

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| XUNFEI_APP_ID | 讯飞星火应用 ID | xxxxxxxx |
| XUNFEI_API_KEY | 讯飞 API Key | xxxxxxxxxxxxxxxxxxxxxxxx |
| XUNFEI_API_SECRET | 讯飞 API Secret | xxxxxxxxxxxxxxxxxxxxxxxx |
| XUNFEI_SPARK_URL | 讯飞 WebSocket URL | wss://spark-api.xf-yun.com/x2 |

### 3.2 可选变量

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| DATABASE_URL | sqlite:///./edu_agent.db | 数据库连接串（生产环境改为 MySQL） |
| JWT_SECRET_KEY | 随机生成 | JWT 签名密钥（生产环境必须设置≥32位随机字符串） |
| CHROMA_DB_PATH | ./chroma_db | ChromaDB 存储路径 |
| OPENAI_COMPAT_BASE_URL | — | 备用 LLM 地址（ARK/Doubao 等 OpenAI 兼容接口） |
| OPENAI_COMPAT_API_KEY | — | 备用 LLM API Key |
| LOG_LEVEL | INFO | 日志级别（DEBUG/INFO/WARNING/ERROR） |

### 3.3 Mock 模式说明

**触发条件**：`XUNFEI_APP_ID` 等核心变量未配置或值为空。

**Mock 模式效果**：
- 对话功能：返回预置的流式文字响应（模拟 LLM 输出）；
- 诊断功能：返回预置的诊断报告（结构完整）；
- 资源生成：返回预置的5类资源内容；
- 路径规划：使用规则策略（不依赖 LLM），功能完整；
- 知识检索：使用本地索引降级（不依赖 ChromaDB）。

**适用场景**：演示展示、评审环境、网络受限场景。

## 六、常见问题排查

### Q1：Python 版本错误

**现象**：启动时报 `ImportError` 或 `SyntaxError`

**解决**：
```bash
python --version  # 确认为 3.10.x
# 若版本不对，下载 Python 3.10 并重新创建虚拟环境
```

### Q2：端口冲突（8000 或 5173 已被占用）

**解决**：
```bash
# 修改后端端口
uvicorn src.loopse.main:app --port 8001

# 修改前端端口（frontend/vite.config.ts 中的 server.port）
# 或启动时指定：
npm run dev -- --port 5174
```

### Q3：ChromaDB 初始化失败

**现象**：启动日志显示 `ChromaDB connection failed`

**解决**：系统会自动降级至本地索引，无需特殊处理。若需启用 ChromaDB：
```bash
pip install chromadb  # 安装（已在 requirements.txt 中，可能需要手动安装）
python scripts/build_knowledge_base.py  # 重建知识库
```

### Q4：讯飞 API 连接失败

**现象**：对话功能显示"LLM服务不可用"

**解决**：
1. 检查 `.env` 中 `XUNFEI_APP_ID` 等变量是否正确；
2. 确认网络可访问 `wss://spark-api.xf-yun.com`；
3. **演示场景可直接使用 Mock 模式**（不配置 API Key，系统自动降级）。

### Q5：数据库文件损坏或不存在

**解决**：
```bash
# 删除旧数据库，重新初始化
rm edu_agent.db  # 或删除 .db 文件
python scripts/init_db.py
```

### Q6：前端 npm 安装失败

**解决**：
```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com
npm install
```
