## 一、系统概述

### 1.1 系统功能简介

Socrates-Cube 是一个面向高校《计算机网络》课程的多智能体自适应学习系统。系统核心特色：

- **三层认知诊断**：不只告诉你"答错了"，而是解释"为什么错"，并定位你的知识盲区；
- **个性化学习资源**：根据你的认知风格自动生成文档、练习题、代码示例、思维导图等；
- **智能学习路径**：基于知识图谱为你规划科学合理的学习顺序；
- **协议仿真实验室**：TCP、HTTP、DNS 等 7 个协议的交互式动画演示；
- **苏格拉底式追问**：AI 导师通过反问引导你自主发现知识盲点。

### 1.2 用户角色

| 角色 | 功能权限 | 典型使用场景 |
|------|---------|-------------|
| 学生 | 全部学习功能 | 日常学习、备考、查漏补缺 |
| 助教 | 学习功能 + 查看诊断结果 | 了解学生共性问题 |
| 管理员 | 全部功能 + 后台管理 | 知识库维护、用户管理 |

### 1.3 系统访问地址

| 服务 | 地址 |
|------|------|
| 学习系统（前端） | http://localhost:5173 |
| API 接口文档 | http://localhost:8000/docs |
| 健康检查 | http://localhost:8000/health |

## 二、快速开始

### 2.1 访问系统

用浏览器打开 `http://localhost:5173`，进入 Socrates-Cube 登录页面。

### 2.2 演示账号

系统预置 3 个演示账号，可直接使用：

| 账号 | 密码 | 账号状态 |
|------|------|---------|
| demo-student-001 | demo123 | 新学生（触发引导流程） |
| demo-student-002 | demo123 | 有学习历史 |
| demo-student-003 | demo123 | 有误解记录（适合演示诊断功能） |

### 2.3 注册新账号

1. 点击登录页"**注册账号**"；
2. 填写用户名（唯一）、密码（≥6位）、邮箱（可选）；
3. 点击注册，自动跳转至新手引导流程。

### 2.4 游客模式

点击"**游客登录**"可免注册体验核心功能（对话、仿真、书库），但学习记录不会保存。

## 三、新手引导（5步式 Onboarding）

首次登录后，系统将自动引导你完成 5 步初始化，帮助 AI 了解你的学习背景：

| 步骤 | 内容 | 目的 |
|------|------|------|
| Step 1 | 选择学习目标（课程学习/考研/认证备考/综合提升） | 设定学习方向 |
| Step 2 | 评估基础水平（滑动评分 1-5，共8个能力维度） | 初始化8维画像基线 |
| Step 3 | 选择认知风格（视觉型/实践型/文字型/类比型） | 确定资源生成偏好 |
| Step 4 | 标记薄弱章节（从第1-7章中选择） | 设定初始学习路径起点 |
| Step 5 | 设置学习时间安排（每周可用时间） | 路径时长估算参考 |

> 完成引导后进入系统主页，所有功能均可使用。可随时在"个人设置"中重置引导流程。

## 四、核心功能操作指南

### 4.1 智能对话（AI 学习问答）

**入口**：左侧导航 → "**智能对话**"（路由：/chat）

#### 基本对话

1. 在底部输入框中输入你的问题或答案；
2. 点击发送（或按 Enter）；
3. AI 的回复将**逐字流式显示**（模拟打字效果）；
4. 右侧面板可看到 Agent 执行链路（哪些 AI 正在工作）。

#### 切换虚拟教师人格

点击对话框顶部的人格切换按钮，可选择 4 种不同风格的 AI 教师：

| 人格 | 特点 | 适用场景 |
|------|------|---------|
| 教授（professor） | 严谨学术，引用标准文献 | 深入理解概念、备考 |
| 工程师（engineer） | 实战代码，关注实现 | 实践项目、找工作 |
| 同学（peer） | 口语化，鼓励探索 | 课前预习、轻松学习 |
| 面试官（interviewer） | 反向追问，挖掘盲点 | 模拟面试、自测 |

#### 查看诊断结果

当你输入一个**答案或解释**时，AI 会自动触发三层诊断，诊断结果出现在对话下方：

- **绿色标签**：答案正确
- **红色标签**：答案有误，展开可看到：
  - L1：错误类型（如"流程遗漏"）
  - L2：缺失的前置知识（如"需先掌握 TCP 状态机"）
  - L3：历史误区模式（如"混淆了 SYN 和 SYN-ACK 的方向"）
  - 干预建议

#### 查看 Agent 执行链路

对话界面右侧或底部有 **Agent 状态栏**，实时显示各 Agent 的执行状态，让你了解 AI 的工作过程。

### 4.2 学习能力画像（/profile）

**入口**：左侧导航 → "**能力画像**"

**主要功能：**
- **雷达图**：8维能力的可视化展示，直观看出强项和弱项；
- **知识掌握度**：20 个知识节点的掌握度进度条；
- **认知风格标签**：当前识别到的学习风格；
- **成长轨迹**：画像随时间的变化曲线。

**更新时机**：每次对话后自动更新（无需手动操作）。

---

### 4.3 诊断面板（/diagnosis）

**入口**：左侧导航 → "**认知诊断**"

**主要功能：**
- 查看历史诊断记录；
- 对每条诊断展开 L1/L2/L3 三层详情；
- 查看"我的误区模式"汇总（反复出现的错误类型）；
- 点击诊断中的知识节点可直接跳转到学习资源。

---

### 4.4 学习资源（/resources）

**入口**：左侧导航 → "**学习资源**"

#### 生成资源

1. 在搜索框中输入知识点名称（如"TCP 滑动窗口"）；
2. 点击"**一键生成全套资源**"；
3. 系统将生成 5 类资源（约 5-15 秒）：

| 资源类型 | 图标 | 内容形式 |
|----------|------|---------|
| 知识文档（doc） | 📄 | Markdown 渲染的概念讲解 |
| 练习题（exercise） | 📝 | 3-5道题目，含答案解析 |
| 代码示例（code） | 💻 | 带注释的可运行代码 |
| 思维导图（mindmap） | 🗺️ | Mermaid 渲染的图形化知识结构 |
| 视频脚本（script） | 🎬 | 分段讲解脚本（含演示指引） |

**认知风格自动适配**：系统会根据你的认知风格调整资源顺序（如视觉型用户优先显示思维导图）。

#### 收藏资源

点击资源卡片右上角的"⭐"可收藏资源，在"**书签**"页面查看所有收藏内容。

### 4.5 学习路径（/path）

**入口**：左侧导航 → "**学习路径**"

**查看学习路径：**

路径以**时间线**形式展示，每个节点代表一个知识点：

- **✅ 已完成**：绿色，可点击查看相关资源；
- **🔵 学习中**：蓝色，当前重点；
- **⚪ 待学习**：灰色，按顺序解锁；
- **🔒 已锁定**：红色，前置知识未掌握。

**查看推荐理由：**

点击任意节点旁的"📋 理由"按钮，查看 AI 为什么推荐你学习这个知识点（三维说明：知识依赖 + 诊断关联 + 学习风格）。

**更新路径：**

路径在每次诊断发现缺失知识点后自动更新，也可点击"**重新规划路径**"手动触发。

### 4.6 协议仿真实验室（/simulator）

**入口**：左侧导航 → "**协议仿真**"

**7 个仿真场景：**

| 场景 | 演示内容 |
|------|---------|
| TCP 三次握手 | 客户端与服务端 SYN/SYN-ACK/ACK 交互时序 |
| TCP 四次挥手 | FIN/ACK 双向关闭的完整状态流转 |
| 滑动窗口 | 发送窗口和接收窗口的动态变化过程 |
| HTTP 请求/响应 | 请求报文与响应报文的字段解析动画 |
| DNS 递归查询 | 从本地 DNS 到根服务器到权威服务器的查询树 |
| TCP 拥塞控制 | 慢启动、拥塞避免、快重传的 cwnd 变化曲线 |
| ARP 地址解析 | 广播帧和单播响应帧的以太网传播过程 |

**操作方法：**

1. 选择仿真场景；
2. 点击"**▶ 开始播放**"查看完整动画；
3. 点击"**⏸ 暂停**"可逐步查看每个步骤；
4. 点击"**◀ 上一步 / ▶ 下一步**"进行步进控制；
5. 拖动"速度"滑块调节动画速度（0.5x ~ 3x）；
6. 点击"**🔄 重置**"返回初始状态。

### 4.7 概念挑战（/challenger）

**入口**：左侧导航 → "**概念挑战**" 或由系统自动触发

**触发时机：**

- 当你在对话中**答错**一道问题时，系统会自动发起挑战；
- 连续学习 **5 轮对话**后，系统自动进入巩固阶段发起挑战。

**挑战流程：**

1. AI 提出第一道中等难度的追问（苏格拉底式，不直接告诉你答案）；
2. 你回答后，AI 根据你的答对情况调整下一道题的难度；
3. 挑战进行 2-5 轮后结束；
4. 结束后系统给出知识掌握度评估和建议。

**操作提示**：诚实回答（不知道可以说"不知道"），AI 会根据你的真实反应给出最有效的引导。

### 4.8 教材书库（/bookhouse）

**入口**：左侧导航 → "**教材书库**"

**主要功能：**

- 浏览系统内置的计算机网络教材（谢希仁《计算机网络》各章节）；
- 点击章节进入 PDF 阅读器，支持放大、缩小、翻页；
- 阅读过程中可选中文字提问（AI 助手即时解答）。

---

### 4.9 PDF 知识库（/bookshelf）

**入口**：左侧导航 → "**知识库**"

**主要功能：**

1. **上传 PDF**：将课程材料上传至系统知识库（支持教材、讲义、论文等）；
2. **知识搜索**：通过关键词搜索知识库中的内容；
3. **基于文档问答**：针对上传的文档进行 AI 问答（RAG 模式，引用来源可见）。

**上传步骤：**
1. 点击"**上传 PDF**"按钮；
2. 选择本地 PDF 文件（单文件 ≤ 50MB）；
3. 等待处理完成（文本提取 + 向量化入库，约 30秒 - 2分钟）；
4. 处理完成后可立即进行问答。

## 七、常见问题（FAQ）

### Q1：系统响应很慢，等了很久没有输出

**原因**：LLM API（讯飞星火）响应延迟，或网络波动。

**解决**：
- 正常情况下 SSE 首字应在 **0.5秒内**出现；如超过 5 秒，可刷新页面重试；
- 如使用 Mock 模式（无 API Key），响应会立即出现；
- 联系管理员确认 LLM 服务是否正常。

### Q2：诊断结果看不懂，什么是 L1/L2/L3？

**解释**：
- **L1（表层）**：AI 认为你的答案属于哪种类型的错误（如"协议层归属错误"）；
- **L2（根因）**：你的错误背后可能缺少什么前置知识（如"需先掌握TCP状态机"）；
- **L3（误区）**：你可能和很多同学一样犯了某个典型错误模式（如"混淆了SYN和ACK的方向"），并给出针对性建议。

### Q3：如何重置我的学习状态（重新开始）

1. 进入"**个人设置**"（右上角头像 → 设置）；
2. 点击"**重置学习数据**"；
3. 确认后系统清空画像和学习记录，并重新进入 5 步引导流程。

### Q4：上传 PDF 失败或很慢

**原因**：大文件处理需要时间，或 ChromaDB 服务不可用。

**解决**：
- 确认 PDF 文件大小 ≤ 50MB；
- 若 ChromaDB 不可用，上传功能可能受限，但基础问答功能正常（使用关键词匹配）。

### Q5：对话界面出现"范围提示"黄色框

**解释**：你的问题超出了计算机网络范围（如询问编程语言、数学等），系统通过"越界防护"机制提示范围限制。此为正常行为，请将问题聚焦在计算机网络相关内容上。

### Q6：思维导图或代码显示为纯文字

**原因**：浏览器 Mermaid 或代码高亮插件未加载（网络受限）。

**解决**：
- 刷新页面；
- 或使用有网络连接的环境访问（Mermaid 需加载 CDN 资源）。

### Q7：演示账号密码忘记了

所有演示账号密码均为 `demo123`（见第二章快速开始）。
