> "若开发过程中使用开源项目、前沿 AI 工具/框架，需在提交文档的显著位置标注名称、来源及相关协议要求；如若使用 AI Coding 工具，给出相关说明。"

## 二、核心 AI 服务声明

### 2.1 讯飞星火大模型（主 LLM）

| 项目 | 内容 |
|------|------|
| 工具名称 | 讯飞星火 Spark-X（科大讯飞） |
| 用途 | 系统核心 LLM，承担对话生成、三层认知诊断、学习资源生成等功能 |
| 接入方式 | WebSocket API（wss://spark-api.xf-yun.com/x2），使用 spark-ai-python SDK |
| SDK 版本 | spark-ai-python ≥ 0.4.5 |
| 来源 | 科大讯飞开放平台（https://xinghuo.xfyun.cn/） |
| 符合赛题要求 | ✅ 满足"需选用科大讯飞相关工具"要求 |

**使用场景：**
- OrchestratorAgent：对话内容生成（流式）
- DiagnosisAgent：L1 表层错误分类、L3 误区干预建议
- ProfilerAgent：LLM 全量画像校准（每5轮）
- ResourceGeneratorAgent：5类学习资源内容生成
- ChallengerAgent：苏格拉底式追问问题生成

### 2.2 ARK/Doubao（备用 LLM）

| 项目 | 内容 |
|------|------|
| 工具名称 | 字节跳动 ARK / Doubao-pro-32k |
| 用途 | 讯飞星火不可用时的备用 LLM（OpenAI 兼容接口） |
| 接入方式 | OpenAI 兼容 REST API |
| 使用条件 | 仅在讯飞星火 API 不可用时启用；默认不激活 |
| 来源 | 火山引擎（https://www.volcengine.com/） |

## 四、AI Coding 工具使用声明

根据赛题要求"如若使用 AI Coding 工具，给出相关说明"，本团队在开发过程中使用了以下 AI 辅助开发工具：

| 工具 | 用途 | 使用范围 |
|------|------|---------|
| 讯飞星火代码助手（iFlyCode） | 代码补全、接口文档理解 | 符合赛题"需选用科大讯飞相关工具"要求 |

**特别声明：**

1. AI Coding 工具仅用于**辅助开发**（代码提示、文档生成），系统的核心架构设计、算法逻辑、业务逻辑均由团队自主设计；
2. 所有代码经过人工审核，确保正确性和原创性；
3. 系统架构（8 Agent 协同、三层诊断、KP-ACU 知识图谱等）为本团队原创设计。
