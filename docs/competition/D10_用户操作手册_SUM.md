## 第一章 系统概述

### 1.1 系统功能简介

Socrates-Cube（苏格拉底方块）是一个面向《计算机网络》课程的AI自适应学习系统。系统通过多智能体协同工作，提供以下核心功能：

- **智能对话**：与AI助教进行苏格拉底式对话，实时诊断学习误区
- **认知诊断**：三层深度分析（表面错误→根因→误区模式），告诉你"为什么错"
- **8维能力画像**：动态追踪学习能力，可视化强弱点分布
- **个性化学习资源**：按知识点一键生成文档/练习题/代码示例
- **智能学习路径**：基于知识图谱前置依赖，规划最优学习顺序
- **协议仿真**：交互式演示TCP/HTTP/DNS等协议运行过程
- **概念挑战**：苏格拉底式追问，深化知识理解

### 1.2 用户角色

| 角色 | 说明 |
|---|---|
| 学生 | 主要用户，使用全部学习功能 |
| 游客 | 使用默认账号（student-001）体验系统，无需注册 |

## 第二章 快速开始

### 2.1 访问系统

1. 确保系统已启动（后端运行在8000端口，前端运行在5173端口）
2. 打开 Chrome/Firefox/Edge 浏览器（推荐Chrome 90+）
3. 访问：`http://localhost:5173`

### 2.2 登录方式

**默认演示账号（推荐体验）**：
- 系统内置 `student-001` 演示账号，无需注册
- 直接访问 `/chat` 页面即可开始对话
- user_id 默认为 `student-001`

**自定义用户**：
- 在对话请求中指定任意 `user_id`（如 `student-zhang-001`）
- 系统自动创建新用户账号，无需注册步骤

## 第三章 核心功能操作指南

### 3.1 智能对话（/chat）

智能对话是系统核心功能，通过AI多Agent协同提供深度学习辅助。

**操作步骤**：

1. 点击左侧导航栏的 **"智能对话"** 或访问 `/chat`
2. 在底部输入框中输入您的问题（1-2000字符）
3. 按 **Enter 键** 或点击 **发送** 按钮
4. 等待系统响应（约1-5秒）

**界面元素说明**：

| 界面元素 | 说明 |
|---|---|
| 聊天消息区 | 显示对话历史，AI回复以卡片形式展示 |
| Agent执行时间线 | 实时显示各Agent（Retriever/Diagnosis/Profiler等）的执行状态 |
| 诊断结果面板 | 当AI检测到您的回答有误时，展示三层诊断详情 |
| 学习资源卡片 | 当您请求"给我生成练习题"时，展示生成的资源 |
| 学习路径面板 | 当您询问"先学什么"时，展示个性化学习路径 |

**触发不同功能的示例问题**：

| 问题类型 | 示例 | 触发的Agent |
|---|---|---|
| 普通问答 | "TCP三次握手是什么意思？" | Retriever + Diagnosis + LLM |
| 请求资源 | "给我生成一道TCP拥塞控制的练习题" | + ResourceGenerator |
| 规划路径 | "我该先学什么？给我一个学习计划" | + PathPlanner |
| 协议演示 | "演示一下TCP三次握手的过程" | Retriever + Diagnosis + LLM |

**诊断结果解读**：

当您的回答包含错误时，诊断面板会展示：
- **表面错误（L1）**：您的具体错误是什么（如"把TCP三次握手误认为两次握手"）
- **根因分析（L2）**：错误的深层原因（如"对TCP连接建立目的理解不足"）
- **误区模式（L3）**：错误所属的知识误区类别（如"握手次数混淆"）
- **干预建议**：系统推荐的学习方式（仿真演示/练习题/对比表格等）

### 3.2 能力画像（/profile）

能力画像展示您在计算机网络各维度的学习能力，随每次对话自动更新。

**操作步骤**：

1. 点击导航栏的 **"能力画像"** 或访问 `/profile`
2. 查看8维能力雷达图（图中各顶点对应一个能力维度）
3. 查看知识点掌握度柱状图（mastery_map中的已学知识点）
4. 查看薄弱点列表（掌握度低于0.5的知识节点）

**8维能力说明**：

| 维度 | 含义 | 对应学习行为 |
|---|---|---|
| 概念理解 | 能否准确理解协议概念 | 能完整解释TCP三次握手的目的 |
| 协议分析 | 能否分析协议执行过程 | 能描述DNS解析的完整步骤 |
| 计算能力 | 能否推导序号/窗口值 | 能正确计算子网地址范围 |
| 错误诊断 | 能否识别并纠正错误 | 能找出网络配置中的问题 |
| 系统设计 | 能否评估网络架构 | 能描述分层架构的优缺点 |
| 知识关联 | 能否建立跨协议联系 | 能解释HTTP/TCP/IP三层关系 |
| 表达清晰 | 回答的结构性和准确性 | 使用准确术语清晰表达 |
| 自我纠正 | 被追问后能否修正 | 在提示下主动发现并修正错误 |

### 3.3 学习资源（/resources）

学习资源页面支持按知识点一键生成三类学习资源。

**操作步骤**：

1. 点击导航栏的 **"学习资源"** 或访问 `/resources`
2. 在输入框中填写目标知识点（如"TCP拥塞控制"）
3. 选择资源类型（知识文档/练习题/代码示例）
4. 选择难度等级（1-5）
5. 点击 **"生成"** 按钮，等待AI生成（约3-8秒）
6. 生成完成后，资源卡片显示在页面中

**三类资源说明**：

| 资源类型 | 内容 | 适用场景 |
|---|---|---|
| 知识文档（doc）| 定义、核心原理、要点总结（Markdown格式）| 初次学习或复习 |
| 练习题（exercise）| 选择题+判断题+简答题，含标准答案 | 知识检验 |
| 代码示例（code）| Python代码，含注释，演示核心逻辑 | 实践理解 |

**历史资源查看**：页面底部展示最近生成的20条资源，可随时翻看。

### 3.4 学习路径（/path）

学习路径基于您的8维画像和知识图谱前置依赖，规划个性化学习顺序。

**操作步骤**：

1. 点击导航栏的 **"学习路径"** 或访问 `/path`
2. 页面自动加载根据当前画像生成的学习路径
3. 点击 **"重新规划"** 可生成新的路径
4. 点击各节点可查看：
   - 当前掌握度（圆弧进度条）
   - 推荐学习理由（三维分析）
   - 建议学习资源类型
5. 完成学习后，点击节点的 **"标记完成"** 按钮更新进度

**路径节点状态说明**：

| 状态 | 含义 | 图标颜色 |
|---|---|---|
| completed（已完成）| 掌握度≥82% | 绿色 |
| in_progress（学习中）| 当前正在学习的节点 | 蓝色 |
| pending（待学习）| 前置知识已满足，可以开始 | 黄色 |
| locked（已锁定）| 前置知识尚未达标 | 灰色 |

### 3.5 协议仿真实验室（/simulator）

协议仿真提供TCP/HTTP/DNS等网络协议的交互式可视化演示。

**操作步骤**：

1. 点击导航栏的 **"协议仿真"** 或访问 `/simulator`
2. 选择要仿真的协议场景（如"TCP三次握手"）

5. 调节参数（如窗口大小、超时时间）观察对协议行为的影响

### 3.6 概念挑战（/challenger）

概念挑战通过苏格拉底式追问，深化对核心概念的理解。

**操作步骤**：

1. 点击导航栏的 **"概念挑战"** 或访问 `/challenger`
2. 系统提出问题，请作答
3. AI对您的回答进行诊断：
   - 回答正确：系统提升难度，提出更深入的问题
   - 回答错误：系统降维引导，用更简单的角度帮助理解
4. 经过2-5轮追问后，挑战结束，系统总结诊断结果

**挑战建议**：诚实作答，不要参考资料；每次挑战5轮以内，重点在于暴露知识盲区。

日志页面展示AI Agent的执行链路，适合技术调试和教学演示。

**操作步骤**：

1. 点击导航栏的 **"Agent日志"** 或访问 `/logs`

4. 点击日志条目展开查看输入状态和输出结果

## 第四章 常见问题（FAQ）

**Q1：系统响应很慢，等了超过10秒还没有回复，是什么原因？**

A：如果系统使用讯飞星火LLM模式，网络延迟可能导致响应变慢。建议：
- 检查网络是否能访问 wss://spark-api.xf-yun.com
- 如无法访问讯飞API，系统将切换Mock模式，响应会很快（<1秒）

---

**Q2：诊断面板显示"无明确模式"是什么意思？**

A：这表示AI在本次分析中没有找到与预定义误解库匹配的误区模式，但仍会提供根因分析和干预建议。"无明确模式"不意味着回答正确，请结合"is_correct"字段判断。

---

**Q3：学习路径一直是相同的节点，怎么刷新？**

A：点击学习路径页面的"重新规划"按钮，系统会基于最新画像重新计算路径。完成练习后标记节点为"完成"状态，画像更新后路径会自动调整。

---

**Q4：资源生成失败（500错误）怎么办？**

A：通常是LLM API调用超时或Mock模式下返回异常。解决方法：
- 刷新页面后重试
- 检查后端服务是否正常运行（访问 http://localhost:8000/health）

---

**Q5：ChromaDB检索提示"来源: local_index"是什么意思？**

A：这表示系统使用了TF-IDF本地索引降级（ChromaDB未初始化）。功能不受影响，但检索相关性可能略低。若希望使用向量检索，请参考安装部署说明执行知识库初始化脚本。

---

**Q6：如何重置学习状态，重新开始？**

A：方法一：使用新的 user_id（如 student-new-001）发起对话，系统自动创建新账号。方法二：使用 POST /api/v1/profile/{user_id} 接口，传入初始化画像数据（所有维度设为0.5）。
