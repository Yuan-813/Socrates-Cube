核心创新一：三层认知诊断框架

L1

表面错误检测（_detect_surface_error）

LLM语义判断 + 关键词硬规则双重机制
"两次握手" → 强制标记 factual 错误（零漏判）

L2

根因分析（_analyze_root_cause）

LLM深度分析认知根源
定位缺失的前置知识节点（missing_prerequisites）

L3

误区模式匹配（_match_pattern）

在 150条误解库（23种错误类型）中匹配
输出标准化干预策略

混合更新策略

策略A：LLM增量校准（每轮对话）

LLM解析对话内容 → 返回各维度 δ ∈ [-0.2, +0.2]
更新公式：score = clamp(score + δ, 0.1, 1.0)

策略B：确定性掌握度更新（每次诊断）

诊断正确：mastery += 0.05
诊断错误：mastery -= 0.07
动态维护 weak_points 和 strong_points

降级设计

LLM失败时：δ为空，仅执行策略B
确保画像始终有合理更新

核心创新三：KP-ACU双层知识图谱 + RAG三库检索

KP-ACU双层建模

KP层（Knowledge Point）

粒度较粗的学习概念（kn_001~kn_010+）
用于学习路径规划、拓扑排序

ACU层（Atomic Cognitive Unit）

细粒度认知单元（acu_001~acu_046+）
与150条误解库精确对应

Kahn拓扑排序（PathPlanner）

计算入度
→
入度0入队
→
按(章节/难度)排序
→
有序路径

RAG三库增强检索

集合内容用途

TF-IDF降级公式

score = Σ (1 + log(tf)) × (log((N+1)/(df+1)) + 1)
ChromaDB不可用时自动降级，对调用方透明

SSE 实时事件流 — Agent执行可视化

标准对话请求的完整SSE事件序列：

agent_start "Orchestrator" ← 意图识别
agent_start "Retriever" ← 三库检索
agent_end "Retriever" ← 命中N条文档
agent_start "Diagnosis" ← 三层诊断
diagnosis {完整10字段结果}
agent_end "Diagnosis"
token ×N ← LLM逐字推送
agent_end "Profiler" ← 画像更新
resource / path_update ← 按需
done {session_id, total_ms}
