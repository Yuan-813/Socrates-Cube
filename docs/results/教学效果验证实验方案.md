## 1. 实验设计概述

### 1.1 研究目的

验证 Socrates-Cube 系统的**三层认知诊断**与**个性化干预路径**是否能显著提升学生在计算机网络核心知识点上的学习效果。

### 1.2 研究假设

| 编号 | 假设内容 | 检验方式 |
|------|---------|---------|
| **H1** | 使用 Socrates-Cube 的实验组学习增益（Normalized Gain）显著高于两个对照组 | 独立样本 t 检验 / Mann-Whitney U |
| **H2** | Socrates-Cube 三层诊断的误解匹配准确率 ≥ 75% | Precision/Recall/F1 |
| **H3** | 实验组学生对系统易用性与诊断有用性的满意度均值 ≥ 3.5（5点量表） | 描述统计 + 单样本 t 检验 |

### 1.3 实验类型

**准实验设计**：前后测对照组设计（Pretest-Posttest Control Group Design）

### 1.4 变量定义

| 变量类型 | 变量名称 | 操作化定义 |
|---------|---------|-----------|
| **自变量** | 学习工具类型 | A=Socrates-Cube / B=通用AI助手 / C=传统自学 |
| **因变量1** | 学习增益 | Hake归一化增益 g = (后测-前测)/(满分-前测) |
| **因变量2** | 诊断准确率 | 三层诊断与专家标注的一致率 |
| **因变量3** | 学习体验 | Likert五维度问卷均分 |
| **控制变量** | 前测成绩、学习时长(120min)、知识点范围(7节点)、学习环境 | — |

## 2. 实验分组与流程

### 2.1 三组设计

| 组别 | 学习工具 | 具体操作 |
|------|---------|---------|
| **A组**（实验组） | Socrates-Cube 完整系统 | 对话诊断→个性化路径→协议仿真→Challenger验证 |
| **B组**（对照组1） | 通用AI助手（ChatGPT/文心一言） | 自由提问+AI辅助习题+AI总结 |
| **C组**（对照组2） | 教材+习题集 | 阅读教材+纸质习题+自行整理笔记 |

### 2.2 样本量建议

- 预期效应量：Cohen's d = 0.8；α = 0.05（双侧）；Power = 0.80
- G*Power计算结果：每组最少 n = 26，**建议每组30人，共90人**
- 若仅一个班(~45人)，可采用两组设计（A vs C，各22-23人）

### 2.3 随机分组方法

按前测成绩**分层随机分配**：成绩三等分（高/中/低），每层内随机分入A/B/C组，确保三组前测均值无显著差异（ANOVA, p>0.05）。

### 2.4 实验流程时间线

| 时间 | 活动 | 时长 |
|------|------|------|
| Day 1 | 知情同意 + 前测 | 30min |
| Day 2-8 | 各组完成学习任务 | 总计120min |
| Day 9 | 后测 + 学习体验问卷 | 45min |
| Day 10-14 | 数据整理与分析 | — |

### 2.5 学习任务设计（120分钟）

**A组任务**：热身对话(10min)→认知诊断(20min)→路径学习(40min)→协议仿真TCP握手+DNS(30min)→Challenger验证(20min)

**B组任务**：自由问答(60min)→AI辅助习题(40min)→AI总结(20min)

**C组任务**：教材阅读第5章5.9-5.11、第6章6.1-6.3(60min)→配套习题(40min)→笔记整理(20min)

## 5. 诊断准确率评测方法

### 5.1 评测方案

收集A组学生错误回答 → 系统三层诊断输出 → 领域专家独立标注 → 计算一致性

### 5.2 评价指标

| 层次 | 指标 | 计算方式 |
|------|------|---------|
| 表层错误检测 | Precision / Recall / F1 | 系统检出错误 vs 专家标注错误 |
| 根因识别 | 一致率 | 系统根因判断 vs 专家判断的匹配百分比 |
| 误解匹配 | 准确率 | 系统输出mc_xxx是否与专家标注一致 |

### 5.3 标注规范

- **标注员**：至少2名计算机网络课程教师/研究生
- **标注流程**：独立标注 → 计算 Cohen's Kappa → 讨论不一致项达成共识
- **Kappa阈值**：κ ≥ 0.6 视为可接受一致性
- **样本量**：至少收集 **50条** 错误回答（预计A组30人×平均2-3个错误可满足）

### 5.4 标注模板

| 学生ID | 错误回答原文 | 专家-表层错误类型 | 专家-根因分析 | 专家-误解ID | 系统-表层 | 系统-根因 | 系统-误解ID | 三层是否一致 |
|--------|------------|-----------------|-------------|------------|---------|---------|-----------|------------|
| S001 | "..." | flow_omission | ... | mc_001 | ... | ... | ... | √/× |

## 6. 学习增益（Learning Gain）计算方法

### 6.1 计算公式

| 指标 | 公式 | 说明 |
|------|------|------|
| 绝对增益 | G = 后测 - 前测 | 直观反映分数提升 |
| Hake归一化增益 | g = (后测 - 前测) / (满分 - 前测) | 消除前测基线差异，范围[0,1] |
| 效应量 | Cohen's d = (M₁ - M₂) / S_pooled | 衡量差异实际大小 |

### 6.2 统计检验

1. **正态性检验**：Shapiro-Wilk（n<50）
2. **方差齐性**：Levene检验
3. **主检验**：
   - 正态+方差齐：独立样本t检验（两组）/ 单因素ANOVA（三组）
   - 不满足：Mann-Whitney U（两组）/ Kruskal-Wallis（三组）
4. **事后比较**：Tukey HSD（ANOVA显著后）
5. **显著性水平**：α = 0.05

## 8. 数据收集与分析流程

### 8.1 数据采集清单

| 数据类型 | 采集方式 | 采集时间 | 负责人 |
|---------|---------|---------|--------|
| 前测答卷 | 纸质/在线 | Day 1 | 实验员 |
| 后测答卷 | 纸质/在线 | Day 9 | 实验员 |
| 学习体验问卷 | 在线问卷星 | Day 9 | 实验员 |
| 系统交互日志 | Socrates-Cube后端日志 | Day 2-8 | 开发者 |
| 诊断输出记录 | 系统数据库导出 | Day 9后 | 开发者 |
| 学习时长记录 | 系统session时间 / 自报 | Day 2-8 | 实验员 |

### 8.2 数据清洗规则

- 剔除前测或后测缺席者
- 剔除学习时长不足90分钟者（严重偏离120min目标）
- 剔除问卷明显规律性作答（如全选同一选项）
- 最终有效样本量不低于每组20人

### 8.3 分析步骤

1. 描述统计（三组前测/后测均值、标准差）
2. 前测组间差异检验（确认基线等价）
3. 学习增益计算与组间比较（H1检验）
4. 诊断准确率统计（H2检验）
5. 问卷信度分析（Cronbach's α ≥ 0.7）
6. 问卷维度均值比较（H3检验）
7. 开放题内容编码与归纳

### 8.4 工具推荐

| 任务 | 推荐工具 |
|------|---------|
| 数据录入与基础统计 | Excel / Google Sheets |
| 统计检验 | Python scipy.stats / SPSS |
| 效应量计算 | Python pingouin 库 |
| 问卷信度 | SPSS 可靠性分析 |
| 图表绑定 | Python matplotlib + seaborn |

## 10. 伦理声明与局限性

### 10.1 知情同意

- 实验前发放《知情同意书》，说明实验目的、流程、数据用途
- 参与者有权随时退出，退出不影响课程成绩
- 未成年参与者需获得监护人签字

### 10.2 数据匿名化

- 所有数据以编号存储（S001-S090），不记录真实姓名
- 系统日志中脱敏处理个人标识信息
- 原始数据仅项目组内部使用，不对外公开个体数据

### 10.3 公平性保障

- 实验结束后，向B组和C组开放Socrates-Cube系统使用权限
- 后测成绩不计入课程正式考核

### 10.4 实验局限性

| 局限 | 说明 | 缓解措施 |
|------|------|---------|
| 样本量有限 | 单班级30-90人，外部效度受限 | 报告效应量，避免过度泛化 |
| 时间跨度短 | 2周实验，无法评估长期保持效果 | 标注为短期效果，建议未来追踪 |
| 单学科验证 | 仅计算机网络，不代表所有学科 | 声明适用范围 |
| 霍桑效应 | 实验组知道被观察可能更努力 | 三组统一告知"学习效果研究" |
| AI助手版本差异 | 通用AI不断迭代，结果有时效性 | 记录使用的具体模型版本 |

### 10.5 未来改进方向

1. 扩大样本：多校多班级联合实验
2. 纵向追踪：加入1个月后延迟后测
3. 多学科推广：扩展到操作系统、数据结构等课程
4. A/B组细分：拆分Socrates-Cube各模块单独验证贡献度
5. 自适应难度：根据前测动态调整学习任务难度
