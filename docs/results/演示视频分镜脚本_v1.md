## 详细分镜

### 镜头 1：首页全景（0:00-0:15）

- **画面**：首页 Hero 区域，深色渐变背景，白色大标题「Socrates Cube」
- **动作**：无操作，静态展示
- **旁白**：「Socrates-Cube 是基于大模型的计算机网络协议误解诊断与个性化学习多智能体系统。」
- **字幕**：系统名称 + Slogan
- **转场**：无

### 镜头 2：首页→对话页（0:15-0:30）

- **画面**：侧边栏「智能对话」入口高亮，页面平滑过渡
- **动作**：鼠标点击「智能对话」菜单项
- **旁白**：「让我们进入智能对话界面，演示核心诊断功能。」
- **转场**：fade-slide 过渡动画

### 镜头 3：输入问题+诊断过程（0:30-1:15）

- **画面**：对话输入框获得焦点，开始输入文字
- **动作**：输入「TCP 握手只需要两次就够了吧？」，按回车发送
- **旁白**：「我以一个典型的学生误区开始——认为 TCP 只需要两次握手。」
- **特写**：
  - 0:35：AgentStatusBar 出现 Orchestrator（蓝色脉冲动画）
  - 0:40：AgentStatusBar 出现 Retriever（绿色），显示「检索知识库...」
  - 0:50：AgentStatusBar 出现 Diagnosis（红色），显示「三层诊断中...」
- **字幕**：各 Agent 名称和状态

### 镜头 4：流式回复+来源标注（1:15-2:00）

- **画面**：AI 回复消息逐字流式输出，Markdown 渲染
- **动作**：无操作，等待流式输出完成
- **旁白**：「系统以苏格拉底式追问引导学生思考——不是直接给答案，而是用反例推动自主推理。回复末尾标注参考来源。」
- **特写**：
  - 1:30：回复内容中的「💡 为什么需要三次而不是两次？」高亮
  - 1:50：底部来源标注「参考来源：[1] 谢希仁《计算机网络》第8版 第5章」特写
- **字幕**：「苏格拉底式追问 + 可信溯源」

### 镜头 5：诊断面板特写（2:00-2:30）

- **画面**：右侧诊断面板，三层递进展示
- **动作**：无操作，面板自动展开
- **旁白**：「三层诊断引擎：第一层识别表层错误为流程遗漏型，第二层溯源根因——未理解第三次 ACK 防止历史连接的作用，第三层匹配误区模式。」
- **特写**：
  - 2:05：第一层卡片展开（红色 badge「1」+ 错误标签）
  - 2:12：第二层卡片展开（橙色 badge「2」+ 根因树）
  - 2:20：第三层卡片展开（紫色 badge「3」+ 模式匹配 + 干预建议）
- **字幕**：「三层认知诊断引擎」

### 镜头 6-7：资源生成（2:30-3:40）

- **画面**：输入「帮我生成 TCP 三次握手的学习资源」
- **动作**：输入并发送，等待资源生成
- **旁白**：「ResourceGenerator 根据诊断结果生成 5 类个性化学习资源——文档、练习题、代码、思维导图、视频脚本。」
- **特写**：
  - 2:50：资源面板卡片依次出现（每张卡片 slide-in 动画）
  - 3:00：知识文档卡片展开，显示 Markdown 渲染内容
  - 3:15：练习题卡片展开，显示选择题+答案解析
  - 3:25：代码示例卡片展开，显示 Python 代码高亮
- **字幕**：「画像驱动资源生成」

### 镜头 8-9：学习路径（3:40-4:50）

- **画面**：切换到学习路径页面，PathTimeline 展示 6 个节点
- **动作**：鼠标点击 kn_005 节点，展开推荐理由详情
- **旁白**：「路径规划基于知识图谱前置依赖、诊断结果和认知风格三维推荐，每个节点都有可解释的推荐理由。」
- **特写**：
  - 3:50：路径全景，节点按状态着色
  - 4:10：节点推荐理由弹窗，三维来源分别展示
- **字幕**：「知识图谱驱动可解释路径」

### 镜头 10：能力画像（4:50-5:30）

- **画面**：8 维雷达图 + 薄弱点/优势点列表
- **动作**：无操作
- **旁白**：「Profiler 在每轮对话后更新 8 维认知画像，动态反映学生能力变化。」
- **特写**：
  - 5:00：雷达图各维度数值标注
  - 5:15：薄弱点列表（kn_005、kn_007）高亮
- **字幕**：「8 维动态画像」

### 镜头 11：Agent 日志（5:30-5:50）

- **画面**：Agent 日志页面，时间线展示各 Agent 运行记录
- **旁白**：「每个 Agent 的入参、出参、耗时都有完整日志，便于验收和调试。」
- **字幕**：「全链路可追溯」

### 镜头 12：协议仿真（5:50-6:20）

- **画面**：仿真播放器，TCP 三次握手时序图动画
- **动作**：点击播放按钮
- **旁白**：「协议仿真器可视化展示 TCP 三次握手的状态变化和报文交互。」
- **特写**：
  - 5:55：客户端发送 SYN，时序图箭头动画
  - 6:00：服务端回复 SYN+ACK
  - 6:08：客户端发送 ACK，连接建立
  - 6:15：状态机变化 CLOSED→SYN_SENT→SYN_RCVD→ESTABLISHED
- **字幕**：「协议仿真可视化」

### 镜头 13：Agent 协同架构（6:20-6:40）

- **画面**：首页核心能力卡片区域，展示「多智能体协同」卡片
- **旁白**：「8 个专业 Agent 分工协作——Orchestrator 协调全局，Retriever 检索知识，Diagnosis 三层诊断，Profiler 维护画像，ResourceGenerator 生成资源，PathPlanner 规划路径，Simulator 协议仿真，Challenger 概念挑战。」
- **字幕**：「8 Agent 多智能体协同架构」

### 镜头 14：总结收尾（6:40-7:00）

- **画面**：首页 Footer，显示团队信息和版本号
- **旁白**：「三大创新：三层认知诊断引擎、8 Agent 多智能体协同、知识图谱驱动可解释路径。系统支持在线和 Mock 离线双模式。谢谢大家！」
- **字幕**：「Socrates Cube v1.0.0 | 软件杯A3」

## 拍摄注意事项

1. **屏幕录制**：1920×1080，30fps，使用 OBS Studio
2. **鼠标光标**：开启鼠标高亮效果
3. **浏览器**：Chrome 全屏模式（F11），缩放 100%
4. **录屏前**：运行 `python scripts/demo_warmup.py` 预热演示数据
5. **录屏后**：裁剪开头结尾，添加片头片尾字幕
