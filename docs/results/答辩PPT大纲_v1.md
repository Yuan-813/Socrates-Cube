## 第 2 页：痛点引入

- **核心信息**：协议学习三大痛点
  1. 协议流程抽象，难以建立直觉（握手/挥手/窗口）
  2. 学生错误模式多样，传统问答无法精准诊断
  3. 学习资源千篇一律，缺乏个性化推荐
- **配图建议**：三栏图标+痛点描述，对比传统 vs 智能
- **讲解时长**：30 秒

  - 8 Agent 协同：编排器 → 检索 → 诊断 → 画像 → 资源 → 路径 → 仿真 → 追问
- **配图建议**：8 Agent 环形协作架构图
- **讲解时长**：30 秒

  - 第三层：误区模式匹配（6 种模式 + 混合模式 + 干预建议）

- **配图建议**：三层递进漏斗图 + 诊断面板截图
- **讲解时长**：1 分钟（配合现场演示）

  - 诊断结果驱动：错误类型 → 题型映射（选择/场景/填空）

## 第 7 页：核心亮点 — 协议仿真可视化 🎯

- **核心信息**：
  - 7 种仿真场景：TCP 握手/挥手/滑动窗口/HTTP 请求/HTTP 封装/DNS/拥塞控制
  - Canvas 动画 + 完整交互：播放/暂停/步进/进度拖拽/全屏/报文详情
  - 参数调节面板：窗口大小/RTT/丢包率，即时重新仿真
- **配图建议**：仿真播放器全屏截图 + TCP 状态机面板
- **讲解时长**：45 秒

## 第 8 页：8 Agent 协同机制

- **核心信息**：
  - Orchestrator（编排器）：状态机调度 + 学习巩固触发
  - Retriever（检索器）：三库联合检索 + 知识图谱
  - Diagnosis（诊断师）：三层认知诊断
  - Profiler（画像师）：八维画像 + 增量更新
  - ResourceGenerator（资源师）：5 类自适应资源
  - PathPlanner（规划师）：图谱路径规划 + 三维理由
  - Simulator（仿真器）：7 场景协议仿真
  - Challenger（追问者）：苏格拉底式对抗检验
- **配图建议**：Agent 调度流程图 + SSE 事件流示意
- **讲解时长**：40 秒

## 第 9 页：系统可信机制

  - 来源溯源：检索来源编号引用 + 末尾参考来源列表

- **配图建议**：三层防护流程图 + 越界拦截截图
