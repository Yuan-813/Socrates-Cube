# Socrates-Cube 黄金演示脚本 v1

> 7 分钟黄金路径，含每步输入话术、预期输出、镜头停留时间

## 演示环境准备

1. 后端：`python -m uvicorn src.loopse.main:app --reload --port 8000`
2. 前端：`cd frontend && npm run dev`
3. 演示账号：`demo-student-001`（初学者-小王，认知风格=visual，进度=低）
4. 备用：Mock 模式 `python -m uvicorn src.loopse.main:app --mock-mode`

---

## 0:00-0:30 | 开场介绍（30 秒）

**镜头**：首页全景 → 侧边栏

**话术**：
> 「大家好，我们团队的项目叫 Socrates-Cube——基于大模型的计算机网络协议误解诊断与个性化学习多智能体系统。系统通过 8 个专业 Agent 协同工作，实现诊断、资源、路径、画像的一体化辅导。」

**操作**：展示首页 Hero 区域 + 三大核心能力卡片

**预期输出**：首页显示系统名称、Slogan、后端状态指示灯绿色

---

## 0:30-2:30 | 核心演示：三层诊断 + 智能回复（2 分钟）

**镜头**：首页 → 点击「智能对话」

**话术**：
> 「我以一个典型的学生错误提问来演示三层诊断引擎。」

**操作**：在对话输入框输入以下内容：
```
TCP 握手只需要两次就够了吧？
```

**预期输出**：
1. AgentStatusBar 依次显示：Orchestrator → Retriever → Diagnosis → Orchestrator（流式回复）
2. 诊断面板显示：
   - 第一层（表层错误）：识别为「流程遗漏型」——把三次握手的 SYN/SYN+ACK/ACK 误记为两次
   - 第二层（根因分析）：未理解第三次 ACK 防止历史失效连接的作用
   - 第三层（模式匹配）：流程遗漏型误解
3. 主回复以苏格拉底式追问引导：「如果只有两次握手，服务端如何确认客户端收到了 SYN+ACK？」
4. 回复末尾有来源标注：「参考来源：[1] 谢希仁《计算机网络》第8版 第5章」

**停留**：诊断面板三层递进展示停留 5 秒，回复流式输出停留 10 秒

---

## 2:30-3:40 | 资源生成演示（1 分 10 秒）

**话术**：
> 「系统根据诊断结果，自动为学生生成个性化学习资源。」

**操作**：继续输入：
```
帮我生成 TCP 三次握手的学习资源
```

**预期输出**：
1. AgentStatusBar 显示：ResourceGenerator 启动
2. 资源面板展示 5 类资源卡片：
   - 知识文档（Markdown 格式，含定义/原理/要点）
   - 练习题（选择题+判断题+简答题，附答案解析）
   - 代码示例（Python 模拟三次握手过程）
   - 思维导图（Mermaid 格式）
   - 视频脚本（结构化 JSON，60-90 秒讲解）
3. 资源卡片右下角显示质量评分（0.75+）

**停留**：资源面板滚动展示 5 类资源，每类停留 3 秒

---

## 3:40-4:50 | 学习路径规划（1 分 10 秒）

**话术**：
> 「系统根据学生画像和知识图谱，自动生成个性化学习路径。」

**操作**：切换到「学习路径」页面

**预期输出**：
1. PathTimeline 显示 6 个节点的学习路径
2. 节点状态：已完成（绿色）、进行中（蓝色）、待解锁（灰色）
3. 每个节点显示推荐理由 + 三维来源：
   - 知识图谱依赖（graph_dependency）
   - 诊断结果关联（diagnosis_result）
   - 认知风格匹配（cognitive_style）
4. 点击 kn_005（TCP 三次握手），展开推荐理由详情

**停留**：路径全景 5 秒，节点推荐理由详情 5 秒

---

## 4:50-5:50 | 能力画像（1 分钟）

**话术**：
> 「Profiler Agent 在每轮对话后更新学生画像，这是 8 维认知能力雷达图。」

**操作**：切换到「能力画像」页面

**预期输出**：
1. 雷达图显示 8 个维度：
   - 概念理解、协议分析、计算能力、错误诊断
   - 系统设计、知识关联、表达清晰、自我修正
2. 画像维度随对话动态更新
3. 底部显示：薄弱点列表、优势点列表、掌握度热力图
4. 右侧显示对话轮次和认知风格标签

**停留**：雷达图 5 秒，薄弱点/优势点列表 5 秒

---

## 5:50-6:30 | 协议仿真演示（40 秒）

**话术**：
> 「系统内置协议仿真器，学生可以可视化观察 TCP 三次握手的交互过程。」

**操作**：切换到「协议仿真」页面

**预期输出**：
1. 仿真场景选择器显示「TCP 三次握手」
2. 播放仿真动画：客户端 SYN → 服务端 SYN+ACK → 客户端 ACK
3. 时序图展示状态变化：CLOSED → SYN_SENT → SYN_RCVD → ESTABLISHED
4. 步骤说明文字逐条出现

**停留**：仿真播放全程 15 秒

---

## 应急预案

| 情况 | 处理方式 |
|------|----------|
| LLM 超时 | 系统自动降级返回友好提示，不影响演示流程 |
| 后端不可用 | 切换 Mock 模式，前端 mockInterceptor 自动接管 |
| 诊断结果为空 | 使用预置演示账号 demo-student-001，已有历史诊断数据 |
| 仿真卡顿 | 降级展示静态时序图截图 |
