# 第1章 计算机网络概述

Collection: course_docs
Chapter: chapter1
Focus: 计算机网络定义、分层体系结构、性能指标

## 计算机网络的功能与组成

计算机网络将地理位置分散的自治计算机通过通信链路和交换设备互连，实现资源共享、信息传递和分布式处理。典型组成包括终端主机、路由器、交换机、链路和协议栈。对学习者而言，理解"网络解决的是端到端通信与协作"比死记设备名称更重要。

## 网络分类与拓扑结构

按覆盖范围可分为局域网 LAN、城域网 MAN 和广域网 WAN。拓扑结构包括总线型、星型、环型和网状结构。现代校园网和企业网多采用层次化星型/网状混合拓扑：接入层连接终端，汇聚层聚合流量，核心层提供高速转发。拓扑选择影响冗余性、扩展性和故障域隔离。

## 性能指标：带宽、时延、丢包与吞吐

带宽描述链路理论传输能力；时延包含传播、传输、排队和处理时延；丢包率反映网络可靠性；吞吐量是实际可达的有效数据传输速率。评估 TCP 性能时必须同时看 RTT 与带宽，因为高带宽长肥管道场景下窗口大小和拥塞控制会显著影响吞吐。

## 协议、接口与服务

协议是通信规则的集合，规定语法、语义和时序。接口描述相邻层之间的交互方式，服务描述某层为上层提供的功能。分层设计降低了系统复杂度，使各层可独立演进。学习时应区分"协议实体运行的设备"和"协议作用的层次"。

## OSI 七层参考模型

OSI 模型自底向上为物理层、数据链路层、网络层、传输层、会话层、表示层和应用层。它提供了教学分析框架，但互联网工程更常使用 TCP/IP 四层/五层模型。七层模型有助于定位错误发生在哪一层，例如 DNS 问题属于应用层，而 IP 分片属于网络层。

## TCP/IP 四层模型

TCP/IP 可概括为网络接口层、网际层、传输层和应用层。网际层以 IP 为核心，负责主机到主机的寻址与转发；传输层通过 TCP/UDP 提供端到端进程通信；应用层承载 HTTP、DNS、SMTP 等协议。HTTP 并不直接运行在 IP 上，而是通常依赖 TCP 或 QUIC。

## 客户/服务器与对等通信

客户/服务器模式中，服务器被动等待连接并提供服务，客户主动发起请求。P2P 模式中节点既可请求也可提供服务。实际系统常混合使用：例如 BitTorrent 文件块交换是 P2P，但节点发现可能依赖中心 tracker。理解通信模式有助于分析连接建立、状态维护和扩展性。

## 互联网体系结构演进

互联网从早期科研网络发展为全球基础设施，关键技术包括分组交换、IP 路由、域名系统和 Web 协议。近年来 HTTPS 普及、QUIC/HTTP3 推广、软件定义网络与边缘计算持续发展。掌握演进脉络有助于理解"为什么新协议要基于 UDP 构建"这类设计取舍。
