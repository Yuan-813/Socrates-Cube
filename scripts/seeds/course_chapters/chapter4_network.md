# 第4章 网络层

Collection: course_docs
Chapter: chapter4
Focus: IP 编址、子网划分、路由选择、NAT 与 ICMP

## 网络层的主要功能

网络层负责将分组从源主机经若干中间路由器转发到目的主机，核心功能包括寻址、路由选择、分组转发和异构网络互连。IP 是 TCP/IP 体系的网络层核心协议，提供无连接、尽最大努力交付服务。与传输层不同，网络层关心的是主机到主机，而非进程到进程。

## IPv4 地址与分类

IPv4 地址由 32 位组成，通常以点分十进制表示。历史上曾使用 A/B/C 类划分，如今更常见的是无类别编址 CIDR。/24 表示前 24 位为网络前缀，剩余 8 位为主机位，可支持 2^8 个地址，但需扣除网络地址和广播地址。把 /24 误解为"24 个主机地址"是典型计算错误。

## 子网划分与路由聚合

子网划分将一个大网络划分为多个更小广播域，提高地址利用率与管理效率。路由聚合将多个前缀汇总为更短前缀，减少路由表规模。配置子网时要同时考虑主机数量、未来扩展和网关位置。VLSM 允许不同子网使用不同掩码长度。

## IP 数据报格式与分片

IPv4 首部包含版本、首部长度、总长度、标识、标志、片偏移、TTL、协议号、首部校验和、源/目的地址等字段。当数据报超过链路 MTU 时，路由器或源主机可进行 IP 分片，接收端负责重组。IP 分片属于网络层行为，不应与 TCP 分段混淆。

## 路由选择的基本概念

路由选择决定分组从源到目的应经过的路径。路由器依据转发表进行下一跳决策。转发表可由静态配置或动态路由协议生成。默认路由用于匹配不到更具体前缀时的兜底转发。理解"最长前缀匹配"是阅读路由表的基础。

## 内部网关协议 RIP 与 OSPF

RIP 基于距离向量，以跳数为度量，实现简单但收敛慢。OSPF 是链路状态协议，通过洪泛链路状态通告并运行 Dijkstra 算法计算最短路径，支持分层区域设计。选择 IGP 时需考虑网络规模、收敛速度和运维复杂度。

## 外部网关协议 BGP

BGP 是互联网 AS 之间的事实标准外部路由协议，属于路径向量协议。BGP 不仅看跳数，还根据策略属性如 AS-PATH、LOCAL-PREF、MED 做决策。BGP 政策路由使不同运营商能够按商业和策略关系控制流量走向。

## NAT 网络地址转换

NAT 将私有地址映射到公网地址，缓解 IPv4 地址短缺。典型部署在边界路由器，修改 IP 地址和端口。NAT 提高了地址复用能力，但破坏了端到端透明性，使某些 P2P、IPsec 和主动入站连接更复杂。认为 NAT 提升端到端透明性是错误理解。

## ICMP 与网络诊断

ICMP 用于报告网络层差错和辅助诊断，例如目的不可达、超时、重定向和 Echo 请求/应答。ping 通常基于 ICMP Echo，traceroute 利用 TTL 递增观察路径。ICMP 工作在网络层，不应被误认为传输层协议。
