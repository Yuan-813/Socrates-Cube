# 第5章 数据链路层

Collection: course_docs
Chapter: chapter5
Focus: 帧封装、MAC 地址、以太网、差错控制与滑动窗口

## 数据链路层的位置与职责

数据链路层在物理层提供的比特传输基础上，将比特组织成帧，并在相邻节点之间提供可靠或不可靠交付。职责包括封装成帧、透明传输、差错检测、介质访问控制和链路管理。交换机主要依据 MAC 地址在二层转发，路由器依据 IP 地址在三层转发。

## 封装成帧与透明传输

发送方将网络层数据报封装进帧头和帧尾，接收方通过帧定界提取数据。透明传输要求帧定界机制能避免数据内容被误判为控制字段，常见方法有字节填充和比特填充。理解成帧有助于分析 MTU、帧开销和链路利用率。

## 差错检测：校验与 CRC

数据链路层通常使用帧校验序列 FCS 检测比特错误，常见实现是 CRC。差错检测能发现错误，但本身不能恢复；恢复依赖重传机制或上层协议。与 TCP 校验不同，链路层校验只保护单跳帧，不保证端到端完整性。

## MAC 地址与 ARP

MAC 地址是链路层设备标识，用于同一广播域内寻址。ARP 将已知 IP 地址解析为对应 MAC 地址，仅作用于本地链路。ARP 不解析域名，域名到 IP 的映射由 DNS 完成。把 ARP 当作域名解析工具是典型层次混淆。

## 以太网与交换机工作原理

以太网采用 CSMA/CD 或全双工交换方式组织链路访问。交换机通过学习源 MAC 与端口映射建立转发表，对未知单播进行泛洪，对已知目的地址进行精确转发。VLAN 可在二层逻辑划分广播域，提高安全性与可管理性。

## 点对点协议 PPP

PPP 常用于拨号、DSL 和串行链路，支持身份认证、链路质量监测和网络层协议协商。它由封装、链路控制协议 LCP 和网络控制协议 NCP 组成。虽然家庭宽带更多见到以太网接入，PPP 仍是理解广域接入的重要案例。

## 停止-等待协议

停止-等待是最简单的可靠传输协议：发送一帧后等待确认，再发下一帧。优点是实现简单，缺点是信道利用率低，尤其在高时延链路上。它帮助理解确认、超时重传和序号的作用，是深入学习滑动窗口协议的起点。

## 后退 N 帧 GBN

GBN 允许发送方在未确认前连续发送多个帧，接收方只按序接收并累积确认。出现差错时，发送方回退到出错帧重新发送及其后的所有帧。窗口大小与序号空间关系需要满足 W <= 2^n - 1，否则可能无法区分新旧帧。

## 选择重传 SR

SR 让接收方缓存乱序但正确的帧，只重传出错帧。相比 GBN，SR 在误码率较高时更高效，但实现更复杂，需要接收窗口和发送窗口协同管理。理解 GBN 与 SR 的差异，有助于掌握 TCP 中累积确认与选择确认的设计动机。
